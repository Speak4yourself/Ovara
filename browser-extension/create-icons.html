Ovara Icon Generator

📝 Instructions

  1. Enter your app name or initials (1-2 characters work best)
  2. Choose your gradient colors (defaults match Ovara brand)
  3. Select icon style
  4. Click "Generate Icons"
  5. Right-click each icon and "Save image as..."
  6. Save as icon16.png, icon48.png, icon128.png
  7. Place in browser-extension/icons/ folder
