# AI Detector Feature - Complete Setup Guide

## Overview

The AI Detector analyzes text to determine if it was generated by AI. It includes:

- **Multiple Detection Methods**: Heuristic analysis, Claude AI, OpenAI GPT-4, and optional GPTZero integration
- **Saved Essays Management**: Same system as Humanizer with shared database
- **PDF Upload Support**: Extract and analyze text from PDF files
- **Tier-Based Features**: Detailed analysis and multiple detectors for Pro/Premium users
- **Real-Time Analysis**: Instant results with confidence scores
- **Export Reports**: Download analysis reports (Pro/Premium)

## Detection Scoring

### Score Interpretation

| Score Range | Label | Meaning | Recommendation |
|------------|-------|---------|----------------|
| 0-30% | Human-Written | Likely written by a human | Safe to use |
| 30-70% | Possibly AI | Mixed signals detected | Review and revise |
| 70-100% | AI-Generated | Likely AI-generated | Humanize before use |

### Detection Methods

1. **Heuristic Analysis** (All tiers)
   - Sentence length uniformity
   - Common AI phrases
   - Passive voice usage
   - Formal language patterns
   - Contraction usage
   - Personal voice markers

2. **Claude AI Detection** (Premium)
   - Advanced pattern recognition
   - Context-aware analysis
   - Writing style assessment

3. **OpenAI GPT-4 Detection** (Pro/Premium with multiple detectors)
   - GPT-specific pattern detection
   - Trained on AI-generated text

4. **GPTZero API** (Optional - Premium)
   - Professional AI detection service
   - Highest accuracy
   - Requires separate API key

## Database Setup

### 1. Run the SQL Script

Navigate to your Supabase Dashboard → SQL Editor and run:

```bash
sql/CREATE_AI_DETECTOR_TABLES.sql
```

This creates:
- `ai_detection_usage` - Tracks weekly detection limits
- `ai_detection_history` - Stores detection results (optional, for analytics)
- Helper functions for usage tracking
- Updates `saved_essays` table if needed

### 2. Verify Tables

```sql
SELECT table_name
FROM information_schema.tables
WHERE table_schema = 'public'
AND table_name IN (
  'ai_detection_usage',
  'ai_detection_history',
  'saved_essays'
);
```

## PDF Extraction

### How It Works

The PDF extraction function:
1. Receives PDF file (max 10MB)
2. Extracts text using pdf.js library
3. Returns cleaned text with word count
4. Falls back to simple extraction if pdf.js fails

### Supported PDFs

✅ Text-based PDFs (selectable text)
✅ Most standard PDF formats
❌ Scanned PDFs (image-based)
❌ Password-protected PDFs
❌ Heavily formatted PDFs (may have issues)

### Troubleshooting PDF Upload

If PDF extraction fails:
1. Try copying text directly from PDF
2. Paste into the text area manually
3. Ensure PDF contains selectable text (not just images)

## Detection Accuracy

### Factors Affecting Accuracy

✅ **Increases accuracy:**
- Longer text (200+ words recommended)
- Clear AI patterns
- Multiple detection methods (Pro/Premium)
- Recent AI models in text

❌ **Decreases accuracy:**
- Very short text (<50 words)
- Mixed human/AI content
- Heavily edited AI text
- Unique writing styles

### Expected Accuracy

- **Single detector (Free/Basic):** 70-80% accurate
- **Multiple detectors (Pro):** 85-90% accurate
- **All methods + GPTZero (Premium):** 90-95% accurate

## Integration with Humanizer

The AI Detector shares the `saved_essays` table with the Humanizer:

1. **Analyze in AI Detector** → Save essay with AI score
2. **Open in Humanizer** → Humanize high-score essays
3. **Re-analyze** → Verify AI score decreased

This creates a complete workflow:
```
Write/Upload → Detect AI → Humanize → Verify
```

## Security & Privacy

### Data Protection

- ✅ Text is not stored permanently (unless user saves essay)
- ✅ All data encrypted in transit
- ✅ Row Level Security (RLS) on all tables
- ✅ Users can only access their own data
- ✅ API keys stored securely in Supabase secrets

### What We Store

- Detection scores
- Usage statistics
- First 500 characters of text (for history/analytics)
- Saved essays (only if user chooses to save)

### What We Don't Store

- Full text of unsaved analyses
- User IP addresses
- Detailed browsing behavior

## Troubleshooting

### "Failed to analyze text"

1. Check edge function is deployed
2. Verify API keys are set correctly
3. Check edge function logs for errors
4. Ensure text is at least 50 words

### "Text too short"

- Minimum 50 words required
- Add more content for accurate analysis
- Short text gives unreliable results

### PDF Upload Fails

1. Ensure file is a valid PDF
2. Check file size (max 10MB)
3. Try extracting text manually
4. Verify edge function is deployed

### High False Positives

If human text scores high:
1. Check for formal language
2. Look for AI-like patterns
3. Try multiple detectors (upgrade to Pro)
4. Consider GPTZero integration
